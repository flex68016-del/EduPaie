# Manuel utilisateur EduPaie

## Enregistrer un élève

1. Cliquez sur l'onglet **Élèves** dans la barre de navigation
2. Cliquez sur le bouton **Ajouter** en haut à droite
3. Remplissez le formulaire :
   - **Nom** : Nom de famille de l'élève
   - **Prénom** : Prénom de l'élève
   - **Classe** : Sélectionnez la classe dans la liste déroulante
   - **Année scolaire** : Année scolaire (ex: 2024-2025)
   - **Total dû** : Montant total des frais scolaires en FCFA
4. Cliquez sur **Valider** pour enregistrer
5. L'élève apparaît dans la liste avec un solde égal au total dû

## Enregistrer un paiement

1. Dans la liste des élèves, double-cliquez sur l'élève concerné
2. Cliquez sur le bouton **Nouveau paiement** dans la fiche de l'élève
3. Remplissez le formulaire :
   - **Montant** : Montant payé en FCFA
   - **Date** : Date du paiement (par défaut, date du jour)
   - **Mode** : Mode de paiement (Espèces, Virement, Chèque, Mobile)
4. Cliquez sur **Valider**
5. Le numéro de reçu est généré automatiquement (ex: REC-2024-000001)
6. Le solde de l'élève est mis à jour automatiquement
7. Un reçu PDF est généré automatiquement

## Imprimer un reçu

### Depuis la fiche de l'élève

1. Double-cliquez sur l'élève dans la liste
2. Dans l'onglet **Historique des paiements**, cliquez sur **Voir reçu** pour le paiement souhaité
3. Le reçu PDF s'ouvre dans le visualiseur par défaut
4. Imprimez le reçu depuis le visualiseur PDF

### Régénérer un reçu

Si vous avez besoin de régénérer un reçu :

1. Double-cliquez sur l'élève
2. Dans l'onglet **Historique des paiements**, cliquez sur **Voir reçu**
3. Le reçu est régénéré avec les mêmes informations

## Consulter le tableau de bord

1. Cliquez sur l'onglet **Tableau de bord** dans la barre de navigation
2. Les 4 indicateurs clés sont affichés :
   - **Nombre d'élèves** : Total d'élèves enregistrés
   - **Total encaissé** : Somme de tous les paiements
   - **Total restant dû** : Somme des soldes non soldés
   - **Élèves non soldés** : Nombre d'élèves avec un solde > 0
3. La liste des élèves avec leur statut est affichée en dessous
4. Vous pouvez filtrer par statut (Tous, Soldé, Partiellement payé, Non payé)

## Rechercher un élève

1. Dans la liste des élèves, utilisez la barre de recherche en haut
2. Tapez le nom ou le prénom de l'élève
3. La liste se filtre automatiquement en temps réel

## Filtrer par classe

1. Dans la liste des élèves, utilisez le filtre par classe
2. Sélectionnez la classe souhaitée dans la liste déroulante
3. Seuls les élèves de cette classe sont affichés

## Modifier un élève

1. Dans la liste des élèves, sélectionnez l'élève à modifier
2. Cliquez sur le bouton **Modifier**
3. Modifiez les informations souhaitées
4. Cliquez sur **Valider**

## Supprimer un élève

⚠️ **Attention** : La suppression d'un élève supprime également tous ses paiements.

1. Dans la liste des élèves, sélectionnez l'élève à supprimer
2. Cliquez sur le bouton **Supprimer**
3. Confirmez la suppression dans la boîte de dialogue

## Consulter l'historique des paiements

1. Double-cliquez sur l'élève dans la liste
2. L'onglet **Historique des paiements** affiche tous les paiements
3. Pour chaque paiement, vous voyez :
   - Numéro de reçu
   - Date
   - Montant
   - Mode de paiement
   - Solde après paiement
